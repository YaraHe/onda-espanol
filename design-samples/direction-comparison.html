配色、Typography 气质、页面背景、导航与按钮性格、弱装饰性均沿用原 A —— 第一眼仍应被认成「这是原来的 Direction A」。 字体色值间距圆角仍为表达方向用的临时值，不是 Design Tokens。
工具条里的 B / C / D 是前几轮的材料，默认收起，可勾回参照。
Direction A  →  A — Refined 的改动清单（可逐条对照检查）：
  1. Divider 收窄用途（最主要的一条）。撤掉「原句 / 翻译 / 记忆点 / 语法」之间的 3 条全宽横线（原 A 里 .block + .block 的顶边）、教学标注内 3 条点线与语法正文顶边。Divider 此后只保留在语法条目（同一区域内确有并列关系）与导航 / 操作区两条功能边界上。
    一屏线数：默认态 8 → 2（只剩导航与操作区两条功能边界）；语法展开后 12 → 5（另增的 3 条都是语法区段内部的并列条目线）。
  2. 一处轻量 Surface（全页唯一）。翻译与核心记忆点同属「理解这一句」这一个学习动作，合并进同一个理解区段：通栏暖色衬底 #F0E9DA，左右出血到内容边缘、无边框 · 无阴影 · 无圆角。因为它是通栏衬底而不是内缩卡片，读作页面里的一段衬底而非浮起的卡片。
  3. 语法分析不包 Surface。用标题 + 展开态 + 内容缩进 22px 表达从属；标题行仍留在主轴（x=22）上，保证「一眼找到语法分析」与「它从属于原句」同时成立。
  4. 原句与教学标注留在页面背景上。保持阅读主轴，不给表面；撤掉点线后，靠原有暖红左轨 + 固定标签列 + 行距建立对照关系。
  5. 阶段刻度。区段内 10–22px / 阶段之间 40px（≈1 : 2 : 4）。停顿落在「读完原句 → 理解句意 → 是否深入语法」之间；留白用来表达内容关系，而不是把页面撑开。
  6. 进入点。分隔线撤掉后由区块标签承担区域识别，因此把它从 --ink-3 #8C8375 略提亮到 #6B6255。
  7. 实现方式可核验。Refined 的 CSS 是「原 A 的 CSS + 一段追加覆盖层」；覆盖层每条选择器都带 [data-dir="ar"]，原 A 的基础声明一条未改。DOM 上只新增了一个分组容器（把翻译与记忆点包在一起），无新增内容、无交互改动。
