# 文档 1 · 需求分析（PRD）

## 1.1 背景与问题

用户用多邻国学习西班牙语，遇到四个具体痛点：

| 编号 | 痛点 | 本质 |
|---|---|---|
| P1 | 口语练习没分数、没说明，读不标准也通过，学不会语气/语调/重音 | 缺「发音质量反馈」 |
| P2 | 句子没有语法规则讲解，靠硬记 | 缺「语法解释」 |
| P3 | 例句生硬，想看到 YouTube/影视里的真实用法 | 缺「真实语境」 |
| P4 | 看句子认识，但一听就陌生 | 缺「听音训练」 |

## 1.2 目标用户

- **主要用户**：用户本人（西班牙语初学者，手机学习为主，非技术背景）。
- **次要用户**：用户的朋友（想分享链接让别人也能体验、持续迭代）。
- 非目标：大规模公开用户、机构、多语言学习者（v1 只做西语）。

## 1.3 产品定位

**不是提供预置课程的句子学习 App**，而是一个**围绕用户自己遇到的一句话的针对性学习工具**：拿到一句西语 → 搞懂它的语法 → 练好它的发音 → 在自己的句子中反复听熟。

一句话核心价值：**「把一句话讲透（语法）+ 读好（发音）+ 听熟（磨耳朵）」**。

## 1.4 第一版范围（MVP）

**做（v1）：**
- 输入、粘贴或文字识别（OCR）自己遇到的西语句子；提供输入示例和首次引导，不提供系统内置句子库或随机一句
- 得到该句的语法讲解（解决 P2）
- 成功讲解后自动收录到按用户隔离的个人句子集合，可跨设备找回和轻量移出；评分历史独立保留
- 录音读该句，得到分数 + 逐词反馈 + **语速**（解决 P1 的发音质量反馈；重音/语调由讲解+示范辅助）
- 听整句及选中问题词的西语示范朗读；首次学习显示已有的**语调文字标注**（重音/连读/停顿/升降调）（辅助 P1）
- **听熟**：选择全部个人句子或自选句子，设置必要参数后主动开始连续播放；中文翻译可在屏幕显示（解决 P4 的第一步）
- 从最近评分找出可靠的薄弱点并轻量复练；刷新后尽可能恢复当前任务与尚未保存的评分
- **邮箱登录/注册**：多用户使用，练习记录云端存储、换设备同步

**不做（v1，留待后续）：**
- 自动检索外部真实例句、系统化预置句子课程
- 复杂听力测验、场景/分数筛选、中文语音播放和复杂句子管理
- **真实语调曲线可视化**（音高曲线）→ 后续版本
- 多语言、单词卡、排行榜、社交 → 不在规划内

## 1.5 用户故事与验收标准

| 故事 | 验收标准（怎么做算满足） |
|---|---|
| US1 贴一句多邻国的句子，看到语法讲解 | 输入 `Yo como manzanas` → 输出含中文翻译、时态、动词变位、语序、重音提示 |
| US2 录下我读的句子，得到分数和具体反馈 | 读错某词 → 可定位该词、查看反馈并听其标准发音；视觉表达遵循 Design System |
| US3 读之前先听母语示范，并看到语调标注 | 点「听示范」→ 播放西语神经语音 + 显示重音/连读/停顿/升降调标注 |
| US4 回顾并复练同一句 | 记录详情显示最近最多 5 次总分变化及最近一次可靠反馈；带着简短目标直接再练，历史明细按需查看 |
| US5 文字识别西语填入输入框 | 拍一张多邻国截图 → 自动识别出西语句子填进输入框（可编辑） |
| US6 空闲时听熟自己的句子 | 点一级导航「听熟」→ 首次默认全部个人句子，之后恢复有效的已保存范围；确认句数后主动开始循环播放，可自选范围及切换屏幕原文/翻译 |
| US7 中断后继续学习 | 刷新跟读页 → 尽可能恢复句子、必要提示及复练目标；已返回但未保存的评分可恢复并重试保存，不恢复录音 |

## 1.6 成功标准（非正式指标）

- 读错时分数明显下降——**打破「读不标准也通过」**。
- 用户能指出自己哪几个词需要改进，以及语速快慢。
- 用户读完讲解后能说出该句的时态和主要语法点。

## 1.7 约束与假设

**约束**
- 开发靠 vibe coding（Claude Code 写代码，用户描述需求）。
- 以手机浏览器为主，需 HTTPS（录音权限必需）。
- 成本敏感：每月几十元可接受。
- 需能分享链接给别人。

**假设**
- 用户可开通 Azure 全球版、DeepSeek、Vercel、Render（已确认能访问国外服务、有 Mastercard 扣账卡）。
- 西语以 `es-ES`（西班牙）为主，`es-MX`（墨西哥）为可选，界面提供切换。
- 无技术背景用户能完成「申请 key + 贴进环境变量」这类简单操作（我会写逐步教程）。
