# 文档 3 · 交互与页面设计（Stage 4 已确认的目标规格）

> 本文档定义产品的信息架构、页面清单、页面结构、用户流程、交互说明、页面状态与数据流，作为 UI 设计与前端开发的依据。
> 本文档描述目标交互，生产实现仍可能处于 Stage 3。未确认的具体控件、短期快照介质与可靠性阈值留待实施设计。

## 3.1 信息架构（IA）

### 3.1.1 产品整体页面树（含从属关系）

```
西语学习工具
├─ 登录页（L0 · 未登录入口）
├─ 选句页（L1 · 首页）
│   ├─ 讲解页（L2）
│   └─ 跟读页（L2）
├─ 听熟页（L1）
│   ├─ 我的句子管理页（L2）
│   └─ 自定义句子选择页（L2）
├─ 记录页（L1）
│   └─ 记录详情页（L2）
└─ 设置页（L0 · 全局）
```

### 3.1.2 页面层级

| 层级 | 定义 | 页面 |
|---|---|---|
| L1 | 一级导航页：底部标签栏直达 | 选句页、听熟页、记录页 |
| L2 | 二级页面：从 L1 进入，顶栏返回 | 讲解页、跟读页、记录详情页、我的句子管理页、自定义句子选择页 |
| L0 | 入口/全局页面：不占一级导航 | 登录页（未登录入口）、设置页（任意页可达） |

### 3.1.3 一级 / 二级导航

**一级导航**（移动端底部标签栏 / 桌面端顶部导航栏），3 项：

| 顺序 | 标签 | 目标页 |
|---|---|---|
| 1 | 选句 | 选句页（首页） |
| 2 | 听熟 | 听熟页 |
| 3 | 记录 | 记录页 |

**二级导航**：L2 页面由 L1 页面入口按钮压栈进入，顶栏「← 返回」回来源页；讲解页 ⇄ 跟读页 为同级互跳。

### 3.1.4 全局入口

| 入口 | 位置 | 行为 |
|---|---|---|
| ⚙️ 设置 | 每个 L1 页面顶栏右侧 | 进入设置页；返回回来源页 |

### 3.1.5 页面从属关系

| 父页面 | 子页面 | 进入路径 |
|---|---|---|
| 选句页 | 讲解页 | 选句页「查询」→ 讲解页 |
| 选句页 | 跟读页 | 讲解页「去跟读」→ 跟读页 |
| 全局 | 听熟页 | 一级导航「听熟」直接进入 |
| 听熟页 | 我的句子管理页 / 自定义句子选择页 | 「朗读范围」旁「我的句子」→ 管理模式；选「自定义」→ 选择模式；顶栏返回回听熟 |
| 记录页 | 记录详情页 | 记录页点某条 → 记录详情页 |
| 全局 | 设置页 | 任意 L1 页顶栏 ⚙️ → 设置页 |
| 全局 | 登录页 | 未登录打开产品 → 登录页 |

> 注：跟读页 也可由 记录详情页「再练一次」进入，属跨父级入口（见 3.2 页面清单）。

### 3.1.6 每页核心任务

| 页面 | 层级 | 核心任务 |
|---|---|---|
| 登录页 | L0 | 邮箱登录/注册，建立用户身份 |
| 选句页 | L1 | 输入或找回自己遇到的句子，开始讲解 |
| 讲解页 | L2 | 看懂句子：翻译、语法、语调标注 |
| 跟读页 | L2 | 听整句/选中词示范 → 朗读评分 → 带着目标再读 |
| 听熟页 | L1 | 配置并执行本人句子的连续听力任务 |
| 我的句子管理页 | L2 | 按收录时间浏览个人句子，重新学习或移出个人集合 |
| 自定义句子选择页 | L2 | 搜索、按日期分组并选择听熟内容；确认后返回听熟 |
| 记录页 | L1 | 查找评分记录并进入回顾 |
| 记录详情页 | L2 | 看最近反馈与总分变化，进入轻量复练 |
| 设置页 | L0 | 管理方言/分享/关于等偏好 |

## 3.3 页面结构

> 每个页面按「区域 → 区块 → 组件」三层描述：区域是纵向大分区；区块是内容区内的逻辑分组；组件是具体 UI 元素（括号内标注嵌套关系）。

### 3.3.1 区域模型

每个页面由以下纵向区域构成（自上而下，按需出现）：

| 区域 | 说明 | 出现页面 |
|---|---|---|
| 顶栏 | 固定；L2 含「← 返回」+ 标题；L1 含标题 + ⚙️ 设置 | 所有页面 |
| 内容区 | 页面主体，可纵向滚动 | 所有页面 |
| 底部操作区 | 按页面任务放置主操作按钮 | 讲解/跟读/记录详情；听熟为 L1，播放操作仍须明显可达 |
| 底部标签栏 | 固定；一级导航：选句 / 听熟 / 记录 | L1 页（选句/听熟/记录） |

### 3.3.2 各页面区块与组件

**登录页（L0 · 入口）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | 标题组件 |
| 内容区 | ① 登录表单区块：邮箱输入框、密码输入框（或 magic link 发送）、「登录 / 注册」主按钮、错误提示 |
| 底部标签栏 | 无（未登录不入主界面） |

**选句页（L1 首页）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | 标题组件；⚙️ 设置入口组件 |
| 内容区 | ① 句子输入框及清楚的输入示例/首次引导 ② 文字识别入口 ③ 最近练习辅助入口 ④「查询」主按钮；从最近练习找回旧句不要求先进入评分记录 |
| 底部标签栏 | 选句 / 听熟 / 记录（三标签） |

**讲解页（L2）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | ← 返回组件；标题组件 |
| 内容区 | ① 原文区块：句子原文 + 语调文字标注（重音/连读/停顿/升降调）② 翻译区块：中文翻译 ③ 核心记忆点区块：最核心记忆点（1–2 条）④ 语法分析区块（可展开/收起，默认收起）：时态·语态 / 动词变位 / 语序结构 / 中英对比（四子项） |
| 底部操作区 | 🎙️去跟读 主按钮 |

> 语调标注、核心记忆点正常必显；若 `annotation` / `memoryTip` 缺失（LLM 未生成），隐藏对应区块并提示「该部分未生成」，不整页报错。
> 无动词句（如「¡Hola!」）：语法分析内「时态·语态 / 动词变位」显示「不适用 / 本句无动词」，翻译、记忆点、语调标注照常。

**跟读页（L2）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | ← 返回组件；标题组件 |
| 内容区 | ① 原文及已有必要发音提示；记录复练时呈现薄弱词与简短目标，完整讲解按需查看 ② 整句示范 + 语速选择器（0.6/0.8/1.0/1.2x）③ 评分结果：总分、三维、语速、逐词反馈；选中可靠对应的原句词后在反馈区按需听该词示范；保留整句示范与「再读一次」 |
| 底部操作区 | 🎙️录音/停止 主按钮 |

**听熟页（L1）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏与引导 | 标题「听熟」；⚙️设置入口；温和的学习引导「让熟悉的句子，慢慢变自然」 |
| 内容区 | ①「朗读范围」标题旁「我的句子」入口 ②「全部」/「自定义」范围与句数 ③ 当前播放句和状态，句下提供单句精听及整组播放/暂停操作 ④ 语速、句间间隔及屏幕原文/译文设置 ⑤ 默认折叠的「查看本次句子」清单，仅展示句子、可用译文和当前播放位置，不在每行提供播放操作 |
| 主操作 | 空闲时底部「开始播放」；整组活动/暂停时由当前句区域提供「单句精听」及「暂停整组／播放整组」；精听时隐藏本次句子清单，并提供暂停/继续精听、上一句、下一句和结束精听；进入页面不自动请求 TTS |
| 底部标签栏 | 选句 / 听熟 / 记录（三标签） |

**个人句子库页面（L2，共用数据组件，按入口进入管理/选择模式）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | ← 返回听熟；标题随模式显示「我的句子」或「选择句子」 |
| 引导与搜索 | 温和说明句；搜索西语原文和中文译文；清空搜索恢复分组浏览，不改草稿 |
| 分组内容 | 按首次收录月份 → 日期 → 句子展示；月份与日期可折叠并显示数量。选择模式提供月/日/单句勾选和部分选中状态；管理模式无勾选控件，展示重新学习/移出 |
| 管理模式 | 按最近收录时间浏览；重新学习只回填原句；移出二次确认并说明练习历史保留 |
| 选择模式 | 已选数量固定易见；搜索期间只逐条选择匹配项；「确认所选」写入并返回听熟，「取消」或返回丢弃草稿 |
| 状态 | 加载/空/无搜索结果/读取错误及重试；大列表使用稳定分页并保持分组计数和排序 |

**记录页（L1）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | 标题组件；⚙️设置入口组件 |
| 内容区 | 记录列表区块（按日期分组）：日期分组标题 + 记录项列表（每条 = 句子 + 最近得分，点击进入记录详情页）；空态组件（无记录时显示「还没有练习记录」） |
| 底部标签栏 | 选句 / 听熟 / 记录（三标签） |

**记录详情页（L2）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | ← 返回组件；标题组件 |
| 内容区 | ① 句子和译文 ② 最近最多 5 次总分变化（固定 0–100 轴；1 次单点、2 次对比、3 次及以上连线）③ 最近一次可靠评分反馈与简短复练目标 ④ 默认收起的历史明细 |
| 底部操作区 | 🔁再练一次 + 📖查看讲解（两按钮并列） |

**设置页（L0）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | ← 返回组件；标题「设置」 |
| 内容区 | ① 学习偏好区块：方言选择 ② 分享区块：分享本工具 ③ 数据区块：清除练习记录并说明个人句子保留 ④ 关于区块：版本、反馈 |

## 3.4 用户流程

> 以「任务」为单位描述端到端流程：目的、前置条件、步骤（用户操作 → 系统处理与反馈）、分支与异常。

### 3.4.1 注册 / 登录

**目的**：建立用户身份，进入主界面。　**前置条件**：未登录。

| 步骤 | 用户操作 | 系统处理与反馈 |
|---|---|---|
| 1 | 打开产品 | 检测登录态，未登录 → 显示登录页 |
| 2 | 输入邮箱 + 密码（或点「发送登录链接」） | 校验输入格式 |
| 3 | 点「登录 / 注册」 | 调 Supabase Auth，返回 token + `user_id` |
| 4 | — | 成功 → 跳转选句页 |

**分支与异常**：邮箱格式错误 → 红字提示；密码错误 / 已注册 → 错误提示；网络失败 → 提示重试。

### 3.4.2 学习一句（主流程）

**目的**：选句 → 讲解 → 跟读 → 评分，完成一次句子学习。　**前置条件**：已登录。

| 步骤 | 用户操作 | 系统处理与反馈 |
|---|---|---|
| 1 | 选句页输入/粘贴、文字识别或从最近练习回填句子 | 更新 `sentence`，查询按钮启用 |
| 2 | 点「查询」 | 调 /api/explain，按钮 loading |
| 3 | — | 成功 → 讲解页展示翻译 / 核心记忆点 / 折叠语法分析；句子按当前用户保守去重收录，失败时保留讲解并单独重试收录 |
| 4 | 点「去跟读」 | 跳跟读页，传 `sentence` + `translation` + `annotation` |
| 5 | （可选）点「听示范」/ 调语速 | 调 /api/tts，播放母语 |
| 6 | 点「录音」→ 朗读 → 点「停止」 | 上传 /api/assess，显示「评估中」 |
| 7 | — | 成功 → 显示总分/三维/语速/逐词反馈/提升方向；选中有可靠对应的词可按需听标准发音 |
| 8 | — | 尽可能保留待保存评分与固定记录 ID，再写 Supabase：保存中 → 已保存；失败 → 保留结果 + 重试（不重评） |
| 9 | （分支）点「再读一次」/「换一句」 | 再读一次保留简短旧目标直到新结果替换；换一句回选句页；待保存时仍有返回保护 |

**分支与异常**：查询失败 → 停留选句页；录音 < 1s → 前置拦截不请求；评估失败 → 按钮恢复；保存失败 → 保留评分并支持重试。刷新后恢复可用任务上下文；录音/评估中断须说明需重录，已返回待保存的评分尽可能恢复，见 3.5.4 和 3.6.3。

### 3.4.3 听熟

**目的**：配置并执行本人句子的连续听力任务。　**前置条件**：已登录。

| 步骤 | 用户操作 | 系统处理与反馈 |
|---|---|---|
| 1 | 一级导航点「听熟」 | 读取本人个人句子和偏好；首次或已存范围值无效时使用全部，有效的已存自定义范围则恢复；显示本次句数及必要设置，列表默认收起，不自动请求 TTS |
| 2 | （可选）选自定义句子、调整语速/间隔与屏幕显示 | 播放范围和参数按用户保存；首次默认全部/1.0×/2 秒/仅显示原文 |
| 3 | 点「开始播放」 | 逐句调用 /api/tts 播放西语并循环；当前句及状态可见 |
| 4 | （可）暂停/继续整组、展开本次句子清单，或从当前句进入单句精听；也可切换页面 | 清单只展示本次范围；精听时隐藏清单并提供暂停/继续、上一句/下一句和结束；离开听熟页即停止音频 |
| 5 | 点击「我的句子」 | 未开始播放时直接打开管理页；播放或暂停时先提示离开将停止本次播放，确认后停止并进入管理页，取消则留在听熟页 |

**分支与异常**：无个人句子 → 引导去选句，禁用空播放；自定义未选有效句 → 提示并禁用开始；旧设置/失效选择安全降级，不自动导入预置句；设置保存失败 → 提示重试，不声称已保存；无网络/TTS 失败 → 提示并可恢复。离开听熟（含前往管理页）会停止当前播放；返回后重新读取已保存偏好和有效自定义选择，不承诺恢复播放位置。中文译文只在屏幕显示，不播放中文音频。

### 3.4.4 回顾

| 2 | 点某条记录 | 进入详情，查看最近最多 5 次总分变化、最近一次可靠反馈及复练目标；历史明细默认收起 |
| 3 | （分支）点「再练一次」/「查看讲解」 | 再练一次直达轻量跟读并保留目标，支持词/整句示范；查看完整讲解按需请求 AI |

## 3.5 交互说明

> 每个可交互元素按「触发条件 → 系统处理 → 反馈方式」三段描述。页面状态（空态/加载态/错误态）从本模块独立，另见「页面状态」模块。

### 3.5.1 导航与返回

| 元素 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 底部标签（L1） | 点击「选句 / 听熟 / 记录」 | 切换当前标签；离开听熟即停止音频 | 页面切换，目标页显示 |
| 当前标签 | 点击当前所在标签 | 不处理 | 无变化 |
| ← 返回（L2） | 点击顶栏「← 返回」 | 回退到来源页 | 页面切换，回到上一页 |
| 换一句 | 点击「换一句」 | 回到选句页并清空当前结果 | 页面切换，输入框清空 |

### 3.5.2 查询

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 按钮状态变化 | 输入框内容变化（输入/粘贴/删除） | 判断是否为空或仅空格 | 空 → 按钮禁用置灰；有内容 → 按钮启用高亮（局部刷新） |
| 发起查询 | 点击「查询」按钮 | 校验非空后，向 /api/explain 发起请求 | 按钮转 loading（spinner）并禁用，防重复提交 |
| 成功回调 | 接口返回 200 | 携带讲解结果跳转讲解页 | 页面跳转至讲解页 |
| 自动收录 | 成功获得讲解 | 按当前用户对个人句子保守去重并写云端 | 收录成功可跨设备找回；失败仍显示讲解、明确提示未收录并仅重试保存 |
| 旧句找回 | 在听熟页进入「我的句子」管理页并点「重新学习」 | 返回选句页并回填原句；查询仍由用户主动触发 | 不因浏览个人句子自动请求 AI |
| 移出个人句子 | 在「我的句子」管理页点「移出」并确认 | 从个人集合及有效听熟候选中移出，不删除该句评分历史 | 明确显示移出结果；再次成功讲解可重新收录 |
| 管理页导航 | 听熟页点「我的句子」；管理页点顶栏返回 | 管理页为听熟页的 L2 子页面；播放/暂停状态前往前须确认停止 | 未播放时直接进入；取消确认时维持当前任务 |
| 失败回调 | 接口返回 4xx/5xx | 按错误码分支（非西语/超长/网络错误） | Toast 提示具体原因，停留选句页，按钮恢复可用 |

### 3.5.3 听示范 + 语速

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 播放 | 点击「听示范」 | 请求 /api/tts 并播放 | 按钮变「⏹ 停止」，开始播放 |
| 停止 | 点击「⏹ 停止」 | 停止播放 | 按钮恢复「听示范」 |
| 调速 | 点击语速选择器（0.6/0.8/1.0/1.2x） | 以新语速重新请求并播放 | 音频以新语速重播，当前值高亮 |
| 选中词示范 | 评分页选中可可靠对应的原句词，点击「听这个词」 | 按当前方言按需请求该词 TTS；不预生成全句各词 | 反馈区呈现加载、播放/停止与失败重试；保留整句示范 |

同页单词与整句示范互斥；开始录音时停止正在播放的示范。复练时仍可听整句及上次薄弱词，但不增加词级专项评分。

### 3.5.4 录音与评分

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 请求权限 | 首次点击「录音」 | 请求麦克风权限 | 浏览器弹权限弹窗 |
| 开始录音 | 权限通过后 | 开始录制 | 按钮变「⏹ 停止」+ 计时 |
| 停止上传 | 点击「⏹ 停止」 | 停止录制，上传 /api/assess（后端转码） | 按钮 loading，显示「评估中」 |
| 时长校验 | 上传前 | 判断录音时长 | < 1s → Toast「没录到声音，请重试」，不发起请求 |
| 成功回调 | 接口返回 200 | 渲染评分，并尽可能先留存评分结果、固定记录 ID 与待保存状态 | 结果区显示总分/三维/语速/逐词反馈/提升方向；待保存不等于已保存 |
| 保存回调 | 结果展示后写 Supabase | 保存成功 → 已保存；保存失败 → 保留结果 + 提示 + 重试 | 重试只保存，不重评；待保存时保留既有页面/浏览器返回保护 |
| 失败回调 | 接口返回错误 | 按错误码分支 | Toast 提示，按钮恢复可用 |

刷新时的恢复与降级：录音中断 → 恢复任务但提示重录；评分请求中断 → 不自动重发、提示重录；评分已返回但未确认保存 → 尽可能恢复结果和固定 ID，先按当前用户核对云端同 ID 记录的评分内容，内容一致才显示已保存，确未保存时用同一 ID 重试；同 ID 内容冲突时保留可用快照并明确提示，不静默覆盖或误判已保存。网络暂时失败保留可用快照、提示重试；数据缺失/过期/无权访问才回到选句空态。不持久化录音，不承诺绝对零丢失。具体内容比较与防冲突机制留待技术设计。

> 并发规则：录音与示范音频互斥；听熟仅在本页播放、离开即停止，因此当前不会与跟读录音并发。未来若引入全局播放条，需在录音时自动暂停。

### 3.5.5 文字识别（OCR）

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 调起 | 点击「📷 文字识别」 | 调起系统拍照/相册 | 系统相机/相册界面 |
| 识别中 | 用户选定图片 | 浏览器端 Tesseract 识别 | 入口按钮 loading |

| 失败回调 | 识别为空/出错 | 不回填 | 输入框下方红字提示「没识别到文字，可手动输入」（非 Toast、非弹窗） |

### 3.5.6 听熟播放

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 范围与自定义选择 | 首次默认「全部」；选择「自定义」 | 打开独立选择模式；以已确认选择作为草稿基线 | 取消/返回丢弃草稿；「确认所选」才保存有效稳定 ID 并返回听熟 |
| 句子库浏览与搜索 | 在听熟选择「我的句子」或「自定义」 | 两种模式共用个人句子数据、搜索和月份→日期→句子分组；搜索西语原文与中文译文 | 管理模式无勾选控件；选择模式支持月/日/单句勾选及部分选中状态。搜索时仅逐条操作匹配句；清除搜索/折叠不会改变草稿 |
| 播放设置 | 调整语速 / 间隔 / 原文或翻译显示 | 更新当前设置并写入 Supabase；失败可重试 | 当前值和保存状态明确，不把失败显示为保存成功 |
| 开始 | 点击「开始播放」 | 从此时起按列表顺序请求并播放西语 TTS | 显示当前句和状态，开始循环播放 |
| 整组暂停/继续 | 点击当前播放句下的「暂停整组」或「播放整组」 | 暂停或恢复当前整组位置；暂停状态下按钮文案为「播放整组」 | 当前句、状态与清单播放标记一致 |
| 单句精听 | 整组已有当前句时，点击当前播放句下的「单句精听」 | 暂停并记住整组位置；为当前句请求一次音频，使用同一音频循环。精听态隐藏本次句子清单 | 当前精听句突出显示，整组不会同时播放 |
| 精听控制 | 精听时点击暂停/继续、上一句或下一句 | 暂停/恢复当前句；按本次播放顺序切换，首尾循环。单句范围时上一句/下一句不可用 | 只有精听模式显示上一句/下一句控制；切句时为新句取得一次音频 |
| 结束单句精听 | 点击「结束精听」 | 中止当前请求/播放并释放精听资源；恢复原整组位置和暂停状态，不自动续播。原组空闲时恢复空闲 | 返回整组后仅显示「单句精听」与「播放整组」操作，用户可主动继续 |
| 显示开关 | 切换「显示原文 / 显示翻译」 | 只更新屏幕文字 | 局部刷新；不合成或播放中文翻译 |
| 离开页面 | 切换标签或离开页面 | 停止连续或精听并释放音频 | 播放停止 |

| 录音态 | 点击「录音」后 | 录音按钮变「⏹ 停止」+ 计时 |
| 加载态 | 点击「停止」后，评估中 | 录音按钮 loading，显示「评估中」 |
| 已评分态 | 评分返回 | 评分结果区显示总分、分项、语速、逐词反馈及有依据的提升方向；反馈由可靠逐词信息和准确度、流利度、完整度等评分信号共同生成。无可靠问题时不虚构词级建议；总分 100 且没有可靠薄弱信号时隐藏提升方向。新评分总分 100 时播放一次短暂、不遮挡结果的轻动效；不增加鼓励文案，不改变「再读一次」「换一句」位置或功能，并尊重减少动态效果设置 |
| 保存中态 | 评分返回后，写 Supabase 中 | 结果保持显示，标注「保存中」 |
| 已保存态 | 写入成功 | 结果保持显示，可放心离开 |
| 保存失败态 | 写入失败（网络/权限/服务异常） | 结果保持显示；提示「保存失败」+ 重试按钮（不重新评分） |
| 错误态（评分失败） | 评分失败 | 评分结果区不显示，按钮恢复（提示见 3.5.4） |
| 恢复态 | 同一标签页刷新或重新载入，短期任务快照有效，且能确认属于当前用户 | 尽可能恢复原句、译文、可用提示与复练目标；已返回但未完成保存的评分恢复结果及待保存状态；云端暂时不可达时保留有效快照与待核对状态，不声称已保存 |
| 中断态 | 录音或评分请求期间刷新 | 提示该次录音或请求已中断，可重新录制；不恢复音频，不自动重新评分 |
| 保存中断态 | 保存期间刷新 | 先查询当前用户云端同一记录 ID 与评分内容；内容一致才显示已保存，确未保存才允许按原 ID 重试；同 ID 内容冲突时保留可用快照并提示冲突，不静默覆盖；网络暂时不可用时保留快照和重试入口 |
| 恢复不可用态 | 快照缺失、过期或无权访问 | 告知无法恢复，提供选句或本人可访问的学习内容入口；不得展示其他用户数据 |

| 环节 | 说明 |
|---|---|
| 进入加载 | 优先接收本次学习任务；同标签页刷新时尝试有效短期快照，并以当前用户已有云端学习数据核对；缺失、过期或无权访问才退回安全空态 |

| 持久化 | 评分结果写入 Supabase；保存未确认前短期保存结果、固定 `recordId` 与待保存状态，刷新后先核对当前用户云端同 ID 的评分内容，再决定显示已保存或重试；内容冲突不得误判已保存或静默覆盖。网络暂时失败不清除有效快照；录音文件不持久化，录音与进行中的评分请求不恢复或自动重发 |

### 3.7.8 设置页

**字段**

| 字段 | 类型 | 来源 | 用途 |
|---|---|---|---|
| `lang` | enum（es-ES / es-MX） | 用户选择 | 方言，决定评估语言 + TTS 音色 |
| `shareUrl` | string | 系统生成 | 分享链接 |

**数据流转**

| 环节 | 说明 |
|---|---|
| 进入加载 | 读云端设置 → 回显 |
| 操作更新 | 切换方言 → 写云端（Supabase）；点分享 → 生成链接；清除本人练习记录时保留个人句子及其有效听熟候选 |
| 页面间传递 | `lang` 被讲解、跟读与听熟页读取（决定评估语言和西语 TTS 音色，单词与整句示范一致） |
| 持久化 | Supabase |
