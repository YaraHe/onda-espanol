# 文档 3 · 交互与页面设计 ✅ 已定稿（结构）

> 本文档定义产品的信息架构、页面清单、页面结构、用户流程、交互说明、页面状态与数据流，作为 UI 设计与前端开发的依据。

## 3.1 信息架构（IA）

### 3.1.1 产品整体页面树（含从属关系）

```
西语学习工具
├─ 登录页（L0 · 未登录入口）
├─ 选句页（L1 · 首页）
│   ├─ 讲解页（L2）
│   └─ 跟读页（L2）
├─ 句子库页（L1）
│   └─ 磨耳朵页（L2）
├─ 记录页（L1）
│   └─ 记录详情页（L2）
└─ 设置页（L0 · 全局）
```

### 3.1.2 页面层级

| 层级 | 定义 | 页面 |
|---|---|---|
| L1 | 一级导航页：底部标签栏直达，状态常驻 | 选句页、句子库页、记录页 |
| L2 | 二级页面：从 L1 压栈进入，顶栏返回 | 讲解页、跟读页、磨耳朵页、记录详情页 |
| L0 | 入口/全局页面：不占一级导航 | 登录页（未登录入口）、设置页（任意页可达） |

### 3.1.3 一级 / 二级导航

**一级导航**（移动端底部标签栏 / 桌面端顶部导航栏），3 项：

| 顺序 | 标签 | 目标页 |
|---|---|---|
| 1 | 选句 | 选句页（首页） |
| 2 | 句子库 | 句子库页 |
| 3 | 记录 | 记录页 |

**二级导航**：L2 页面由 L1 页面入口按钮压栈进入，顶栏「← 返回」回来源页；讲解页 ⇄ 跟读页 为同级互跳。

### 3.1.4 全局入口

| 入口 | 位置 | 行为 |
|---|---|---|
| ⚙️ 设置 | 每个 L1 页面顶栏右侧 | 进入设置页；返回回来源页 |

### 3.1.5 页面从属关系

| 父页面 | 子页面 | 进入路径 |
|---|---|---|
| 选句页 | 讲解页 | 选句页「查询」→ 讲解页 |
| 选句页 | 跟读页 | 讲解页「去跟读」→ 跟读页 |
| 句子库页 | 磨耳朵页 | 句子库页右上角 🎧 → 磨耳朵页 |
| 记录页 | 记录详情页 | 记录页点某条 → 记录详情页 |
| 全局 | 设置页 | 任意 L1 页顶栏 ⚙️ → 设置页 |
| 全局 | 登录页 | 未登录打开产品 → 登录页 |

> 注：跟读页 也可由 记录详情页「再练一次」进入，属跨父级入口（见 3.2 页面清单）。

### 3.1.6 每页核心任务

| 页面 | 层级 | 核心任务 |
|---|---|---|
| 登录页 | L0 | 邮箱登录/注册，建立用户身份 |
| 选句页 | L1 | 确定要学习的句子 |
| 讲解页 | L2 | 看懂句子：翻译、语法、语调标注 |
| 跟读页 | L2 | 练好发音：听示范 → 朗读 → 评分 + 提升方向 |
| 句子库页 | L1 | 浏览/选句；磨耳朵入口 |
| 磨耳朵页 | L2 | 被动听力练习 |
| 记录页 | L1 | 查看练习记录列表 |
| 记录详情页 | L2 | 查看某句练习历史与得分 |
| 设置页 | L0 | 管理方言/分享/关于等偏好 |

## 3.3 页面结构

> 每个页面按「区域 → 区块 → 组件」三层描述：区域是纵向大分区；区块是内容区内的逻辑分组；组件是具体 UI 元素（括号内标注嵌套关系）。

### 3.3.1 区域模型

每个页面由以下纵向区域构成（自上而下，按需出现）：

| 区域 | 说明 | 出现页面 |
|---|---|---|
| 顶栏 | 固定；L2 含「← 返回」+ 标题；L1 含标题 + ⚙️ 设置 | 所有页面 |
| 内容区 | 页面主体，可纵向滚动 | 所有页面 |
| 底部操作区 | 固定；放置该页主操作按钮 | L2 页（讲解/跟读/磨耳朵/记录详情） |
| 底部标签栏 | 固定；一级导航：选句 / 句子库 / 记录 | L1 页（选句/句子库/记录） |

### 3.3.2 各页面区块与组件

**登录页（L0 · 入口）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | 标题组件 |
| 内容区 | ① 登录表单区块：邮箱输入框、密码输入框（或 magic link 发送）、「登录 / 注册」主按钮、错误提示 |
| 底部标签栏 | 无（未登录不入主界面） |

**选句页（L1 首页）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | 标题组件；⚙️ 设置入口组件 |
| 内容区 | ① 输入区块：句子输入框（多行文本）② 辅助输入区块：📷文字识别 / 🎲随机一句 / 📚从句子库选（三按钮并列一行）③ 最近练习区块：标题 + 最近句子列表（列表项 = 句子，点击回填输入框）④ 🔍查询 主按钮（固定于内容区底部） |
| 底部标签栏 | 选句 / 句子库 / 记录（三标签） |

**讲解页（L2）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | ← 返回组件；标题组件 |
| 内容区 | ① 原文区块：句子原文 + 语调文字标注（重音/连读/停顿/升降调）② 翻译区块：中文翻译 ③ 核心记忆点区块：最核心记忆点（1–2 条）④ 语法分析区块（可展开/收起，默认收起）：时态·语态 / 动词变位 / 语序结构 / 中英对比（四子项） |
| 底部操作区 | 🎙️去跟读 主按钮 |

> 语调标注、核心记忆点正常必显；若 `annotation` / `memoryTip` 缺失（LLM 未生成），隐藏对应区块并提示「该部分未生成」，不整页报错。
> 无动词句（如「¡Hola!」）：语法分析内「时态·语态 / 动词变位」显示「不适用 / 本句无动词」，翻译、记忆点、语调标注照常。

**跟读页（L2）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | ← 返回组件；标题组件 |

**磨耳朵页（L2）**

|---|---|

**记录页（L1）**

| 区域 | 区块 / 组件（含嵌套） |
|---|---|
| 顶栏 | 标题组件；⚙️设置入口组件 |
| 内容区 | 记录列表区块（按日期分组）：日期分组标题 + 记录项列表（每条 = 句子 + 最近得分，点击进入记录详情页）；空态组件（无记录时显示「还没有练习记录」） |

## 3.4 用户流程

> 以「任务」为单位描述端到端流程：目的、前置条件、步骤（用户操作 → 系统处理与反馈）、分支与异常。

### 3.4.1 注册 / 登录

**目的**：建立用户身份，进入主界面。　**前置条件**：未登录。

| 步骤 | 用户操作 | 系统处理与反馈 |
|---|---|---|
| 1 | 打开产品 | 检测登录态，未登录 → 显示登录页 |
| 2 | 输入邮箱 + 密码（或点「发送登录链接」） | 校验输入格式 |
| 3 | 点「登录 / 注册」 | 调 Supabase Auth，返回 token + `user_id` |
| 4 | — | 成功 → 跳转选句页 |

**分支与异常**：邮箱格式错误 → 红字提示；密码错误 / 已注册 → 错误提示；网络失败 → 提示重试。

### 3.4.2 学习一句（主流程）

**目的**：选句 → 讲解 → 跟读 → 评分，完成一次句子学习。　**前置条件**：已登录。

| 步骤 | 用户操作 | 系统处理与反馈 |
|---|---|---|
| 1 | 选句页输入 / 文字识别 / 随机 / 句库选 | 更新 `sentence`，查询按钮启用 |
| 2 | 点「查询」 | 调 /api/explain，按钮 loading |
| 3 | — | 成功 → 讲解页展示翻译 / 核心记忆点 / 折叠语法分析 |
| 4 | 点「去跟读」 | 跳跟读页，传 `sentence` + `translation` + `annotation` |
| 5 | （可选）点「听示范」/ 调语速 | 调 /api/tts，播放母语 |
| 6 | 点「录音」→ 朗读 → 点「停止」 | 上传 /api/assess，显示「评估中」 |
| 7 | — | 成功 → 评分结果区显示总分/三维/语速/逐词高亮/提升方向（已评分） |
| 8 | — | 写 Supabase：保存中 → 已保存；保存失败 → 保留结果 + 提示 + 重试（不重评） |
| 9 | （分支）点「再读一次」/「换一句」 | 再读一次 → 回步骤 6；换一句 → 回选句页（保存失败/保存中时提示「结果未保存」） |

**分支与异常**：查询失败 → Toast 停留选句页；录音 < 1s → 前置拦截不请求；评估失败 → Toast 按钮恢复；保存失败 → 保留评分结果、提示并支持重试（不重评）。

### 3.4.3 磨耳朵

**目的**：对内置句库和已练句子做被动听力练习。　**前置条件**：已登录。

| 步骤 | 用户操作 | 系统处理与反馈 |
|---|---|---|
| 1 | 句子库页点右上角 🎧 | 进入磨耳朵页 |
| 2 | 设置朗读范围 / 语速 / 间隔 / 显示开关；选自定义时从去重候选列表多选 | 生成播放列表并将播放偏好及自定义选择保存到 Supabase；首次默认全部 / 1.0× / 2 秒 / 仅显示原文 |
| 3 | 点「▶ 开始播放」 | 逐句调 /api/tts，循环播放，当前句高亮 |
| 4 | （可）点单句 / 暂停 / 返回 | 单句重播 / 暂停 / 离开页面停止播放 |

**分支与异常**：已学无记录或自定义未选句 → 提示且不能开始空播放；设置读取或保存失败 → 明确提示并可重试，不将未保存的设置显示为已保存；无网络 / 单句失败 → 提示并停止。失效的自定义选择不计数、不播放。

## 3.5 交互说明

> 每个可交互元素按「触发条件 → 系统处理 → 反馈方式」三段描述。页面状态（空态/加载态/错误态）从本模块独立，另见「页面状态」模块。

### 3.5.1 导航与返回

| 元素 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 底部标签（L1） | 点击「选句 / 句子库 / 记录」 | 切换当前标签，各页状态保留 | 页面切换，目标页显示 |
| 当前标签 | 点击当前所在标签 | 不处理 | 无变化 |
| ← 返回（L2） | 点击顶栏「← 返回」 | 回退到来源页 | 页面切换，回到上一页 |
| 换一句 | 点击「换一句」 | 回到选句页并清空当前结果 | 页面切换，输入框清空 |

### 3.5.2 查询

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 按钮状态变化 | 输入框内容变化（输入/粘贴/删除） | 判断是否为空或仅空格 | 空 → 按钮禁用置灰；有内容 → 按钮启用高亮（局部刷新） |
| 发起查询 | 点击「查询」按钮 | 校验非空后，向 /api/explain 发起请求 | 按钮转 loading（spinner）并禁用，防重复提交 |
| 成功回调 | 接口返回 200 | 携带讲解结果跳转讲解页 | 页面跳转至讲解页 |
| 失败回调 | 接口返回 4xx/5xx | 按错误码分支（非西语/超长/网络错误） | Toast 提示具体原因，停留选句页，按钮恢复可用 |

### 3.5.3 听示范 + 语速

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 播放 | 点击「听示范」 | 请求 /api/tts 并播放 | 按钮变「⏹ 停止」，开始播放 |
| 停止 | 点击「⏹ 停止」 | 停止播放 | 按钮恢复「听示范」 |
| 调速 | 点击语速选择器（0.6/0.8/1.0/1.2x） | 以新语速重新请求并播放 | 音频以新语速重播，当前值高亮 |

### 3.5.4 录音与评分

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 请求权限 | 首次点击「录音」 | 请求麦克风权限 | 浏览器弹权限弹窗 |
| 开始录音 | 权限通过后 | 开始录制 | 按钮变「⏹ 停止」+ 计时 |
| 停止上传 | 点击「⏹ 停止」 | 停止录制，上传 /api/assess（后端转码） | 按钮 loading，显示「评估中」 |
| 时长校验 | 上传前 | 判断录音时长 | < 1s → Toast「没录到声音，请重试」，不发起请求 |
| 成功回调 | 接口返回 200 | 渲染评分结果 | 局部刷新：评分结果区显示总分/三维/语速/逐词高亮/提升方向 |
| 保存回调 | 结果渲染后写 Supabase | 保存成功 → 已保存；保存失败 → 保留结果 + 提示 + 重试 | 顶部提示「保存失败」+ 重试按钮（不重评） |
| 失败回调 | 接口返回错误 | 按错误码分支 | Toast 提示，按钮恢复可用 |

> 并发规则：录音与磨耳朵播放互斥。v1 中磨耳朵仅在磨耳朵页内播放、离开页面即停止，因此不会与录音并发；未来 v2 引入全局播放条后，点击录音时应自动暂停磨耳朵。

### 3.5.5 文字识别（OCR）

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 调起 | 点击「📷 文字识别」 | 调起系统拍照/相册 | 系统相机/相册界面 |
| 识别中 | 用户选定图片 | 浏览器端 Tesseract 识别 | 入口按钮 loading |
| 成功回调 | 识别出文字 | 回填输入框 | 输入框局部刷新，出现文字（可编辑） |
| 失败回调 | 识别为空/出错 | 不回填 | 输入框下方红字提示「没识别到文字，可手动输入」（非 Toast、非弹窗） |

### 3.5.6 磨耳朵播放

| 环节 | 触发条件 | 系统处理 | 反馈方式 |
|---|---|---|---|
| 范围与自定义选择 | 选择已学 / 全部 / 自定义；自定义时多选候选句 | 已学取本人已练句，全部取句库与本人已练句的去重合集，自定义取其中选中的有效句；偏好写入 Supabase | 预览列表随选择更新；无可播放句时提示并禁用开始 |

| 开始 | 点击「▶ 开始播放」 | 按列表顺序请求并播放 TTS | 按钮变「⏸ 暂停」，开始循环播放 |
| 暂停 | 点击「⏸ 暂停」 | 暂停播放 | 按钮变「▶ 开始播放」 |
| 单句重播 | 点击列表某句 | 播放该句 | 该句高亮，播放该句 |
| 显示开关 | 切换「显示原文 / 显示翻译」 | 更新显示 | 列表局部刷新 |
| 离开页面 | 点「← 返回」或切标签 | 停止播放并释放音频 | 播放停止，回到来源页 |

## 3.7 数据流

### 3.7.0 登录页

**字段**

| 字段 | 类型 | 来源 | 用途 |
|---|---|---|---|
| `email` | string | 用户输入 | 登录/注册凭证 |
| `password` | string | 用户输入 | 登录/注册凭证 |

| 环节 | 说明 |

**字段**

| 字段 | 类型 | 来源 | 用途 |
|---|---|---|---|

**数据流转**

| 环节 | 说明 |
|---|---|

### 3.7.2 讲解页

**字段**

| 字段 | 类型 | 来源 | 用途 |
|---|---|---|---|
| `sentence` | string | 选句页 / 句子库 / 记录详情 | 原文展示 + 讲解入参（仅句子库/记录详情进入时） |

| `explanation.verbs` | array | /api/explain | 动词变位 |
| `explanation.structure` | string | /api/explain | 语序结构 |
| `explanation.annotation` | object | /api/explain | 语调标注 |
| `explanation.memoryTip` | string | /api/explain | 核心记忆点 |
| `explanation.compare` | string | /api/explain | 中英对比 |

**数据流转**

| 环节 | 说明 |
|---|---|
| 进入加载 | 选句页进入：接收讲解结果（含 `sentence`）→ 直接渲染；句子库 / 记录详情进入：接收 `sentence` → 请求 /api/explain → 渲染讲解 |

| 页面间传递 | 「去跟读」→ `sentence` + `translation` + `annotation` 传跟读页 |
| 持久化 | 讲解结果会话内，不持久化 |

### 3.7.3 跟读页

**字段**

| 字段 | 类型 | 来源 | 用途 |
|---|---|---|---|
| `sentence` | string | 讲解页 / 记录详情 | 原文 + 评估参考文本 |
| `annotation` | object（可选） | 讲解页（去跟读时） | 语调标注渲染；记录详情「再练一次」进入时缺省，隐藏标注区块 |
| `translation` | string | 讲解页 / 记录详情 | 存入练习记录 |
| `demoAudio` | audio | TTS | 示范播放 |
| `recording` | audio | 麦克风 | 评估输入 |
| `result.overall` / `accuracy` / `fluency` / `completeness` | number | /api/assess | 总分 / 三维分 |
| `result.speakingRate` | object | /api/assess | 语速 |
| `result.words` | array | /api/assess | 逐词反馈 |
| `result.suggestions` | string[] | /api/assess | 提升建议 |

**数据流转**

| 环节 | 说明 |
|---|---|
| 进入加载 | 讲解页进入：接收 `sentence` + `translation` + `annotation`；记录详情「再练一次」进入：接收 `sentence` + `translation`，`annotation` 缺省（隐藏语调标注区块） |
| 操作更新 | 听示范 → 生成 `demoAudio`；录音 → 上传 → 返回 `result` |
| 页面间传递 | `result` 写回练习记录 |
| 持久化 | `result` → Supabase；保存失败则保留结果 + 提示重试（不重评）；音频不持久化 |

### 3.7.5 磨耳朵页

**字段**

| 字段 | 类型 | 来源 | 用途 |
|---|---|---|---|
| `scope` | enum（learned / all / custom） | 云端偏好 / 用户选择 | 播放范围；首次默认 all |
| `rate` | number | 云端偏好 / 用户设置 | 语速；首次默认 1.0× |
| `interval` | number | 云端偏好 / 用户设置 | 句间间隔；1 / 2 / 4 秒，首次默认 2 秒 |
| `showText` / `showTranslation` | boolean | 云端偏好 / 用户设置 | 显示开关；首次仅显示原文 |
| `customSelection` | 句子引用集合 | 云端偏好 / 用户多选 | 自定义范围的选中句；具体标识方式由实现确定 |
| `playlist` | string[] | 内置句库 + 本人练习记录按范围筛选并去重 | 待播放句子；忽略已失效选择 |
| `audio` | audio | TTS | 播放音频 |

**数据流转**

| 环节 | 说明 |
|---|---|
| 进入加载 | 从 Supabase 读取本人播放偏好及练习记录；按 `scope` 从句库与已练句的去重合集生成 `playlist`，自定义只取当前有效选中句 |
| 操作更新 | 调设置或自定义多选 → 更新播放列表并保存偏好；点播放 → 逐句请求 TTS；保存失败提示重试 |
| 页面间传递 | 离开页面停止播放（无跨页传递） |
| 持久化 | 范围、语速、间隔、显示开关及自定义选择 → Supabase `user_settings`；音频不持久化；失效选择不计数、不播放 |

|---|---|---|---|
| `records` | array | 云端练习记录 | 记录列表（按日期分组） |

**数据流转**

| 环节 | 说明 |
|---|---|

### 3.7.7 记录详情页

**字段**

| 字段 | 类型 | 来源 | 用途 |
|---|---|---|---|
| `sentence` | string | 记录页 | 原文 |
| `translation` | string | 记录页 | 中文翻译 |
| `history` | array | 云端练习记录（该句） | 历次得分 |

**数据流转**

| 环节 | 说明 |
|---|---|
| 进入加载 | 按 `sentence` 读该句历次记录 |
| 操作更新 | 点「再练一次」/「查看讲解」 |
| 页面间传递 | 「再练一次」→ `sentence` + `translation` 传跟读页；「查看讲解」→ 传讲解页 |
| 持久化 | Supabase |

### 3.7.8 设置页

| 持久化 | Supabase |
