# 文档 2 · 功能设计 + 功能规格（Stage 4 已确认的目标规格）

> 本文档记录已批准的 Stage 4 产品方向；产品代码与数据库仍可能处于 Stage 3 状态。待定的工程细节不因写入目标规格而视为已获批准。

## 2.1 功能清单

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| F1 | 句子输入 | 输入/粘贴 + **文字识别（OCR）** + 个人句子找回 | 高 |
| F2 | 语法讲解 | 调 LLM，结构化返回（含**语调/重音/连读文字标注**） | 高 |
| F3 | 口语评估 | 录音 → Azure 评估 → 三维分 + **语速** + 逐词反馈 | 高 |
| F4 | 示范朗读 | Azure TTS 整句与选中词音频 + 已有**语调文字标注** | 高 |
| F5 | 练习历史与复练 | 云端评分记录、最多 5 次总分变化、最近反馈与轻量复练 | 中 |
| F6 | 方言切换 | es-ES / es-MX | 低 |
| F7 | 文字识别（OCR） | Tesseract.js（免费），识别西语填入输入框 | 低 |
| F8 | 听熟 | 对个人句子配置并执行连续听力任务；屏幕翻译可隐藏 | 中 |
| F9 | 个人句子集合 | 成功讲解后自动收录、去重、跨设备找回、轻量移出 | 高 |
| F10 | 跟读任务恢复 | 标签页短期快照 + 已有云端数据，恢复任务及待保存评分 | 中 |

## 2.2 F1 句子输入

- **输入方式**：① 手动输入/粘贴；② 「文字识别」（F7，识别后可编辑）；③ 从本人个人句子管理页重新学习旧句（该页由听熟进入）。首页保留清楚的输入示例、首次引导和最近练习回填。
- **最近练习**：显示最近最多 5 个不同句子，按最近练习时间由新到旧排列；从完整的当前用户练习历史逐页查找，直到找到 5 个不同句子或历史耗尽。同句身份沿用统一保守规则，反复练习同一句不挤掉其他最近练习过的句子。
- **内容边界**：用户自己遇到的句子是学习内容来源；取消面向用户的内置原创句子库、「从句子库选」和「随机一句」。输入示例只解释如何开始，不构成系统课程或句子库。
- **规则**：句子 1–30 词；超长截断提示；空输入时动作按钮置灰。

## 2.3 F2 语法讲解（规格）

**输入**：`sentence`（西语句子，1–30 词）、`lang`（es-ES / es-MX）。

**输出**（结构化 JSON，前端按区展示）：

```json
{
  "translation": "图书馆在哪里？",
  "tenseMood": "现在时 · 陈述式",
  "verbs": [
    { "form": "está", "infinitive": "estar", "person": "第三人称单数",
      "notes": "estar 表位置，规则变位" }
  ],
  "structure": "疑问副词 ¿Dónde? + 动词 está + 主语 la biblioteca",
  "annotation": {
    "stress":   [ { "word": "biblioteca", "syllable": "te", "display": "biblioTEca" } ],
    "liaison":  [ { "words": "los amigos", "pronounced": "lo.sa.mi.gos", "note": "元音连读" } ],
    "pauses":   [ { "after": "¿Dónde", "type": "短停" } ],
    "pitchPattern": "疑问句：整体先平，句末升调 ↗"
  },
  "memoryTip": "问地点用 ¿Dónde + estar?",
  "compare": "西语疑问句用倒问号 ¿，语序与中文「图书馆在哪」不同，主谓常后置"
}
```

**边界情况**：空输入→报错；非西语→提示「看起来不是西班牙语，请确认」；含专有名词/数字→照常讲解但标注不翻译项。`translation`/`structure` 缺失或空、`verbs`/`tenseMood` 缺失或类型错误，以及服务端可确定的明显矛盾→重试一次，仍无效返回 `EMPTY_UPSTREAM`。真正无动词句（如「¡Hola!」）允许 `verbs: []`、`tenseMood: "不适用"`；但这两个字段彼此矛盾、`structure` 明确标有动词成分却返回空列表，或原句命中现有有界高置信词形规则却返回空列表时，均须按上游无效结果处理。具体规则以[文档 6](06-API.md) 的 `/api/explain` 契约为准。非关键字段（`annotation`/`memoryTip`/`compare`）缺失或异常时不应导致整页报错：讲解页对 `memoryTip`/`compare` 显示明确缺失提示；有效 `annotation` 保留给跟读页，缺失或无效时跟读页不伪造提示。

**成功后的个人收录**：获得可展示的成功讲解后，将原句与可用译文收录到当前用户的个人句子集合；重复查询按 F9 的共享句子身份规则去重。收录失败不撤销讲解：明确提示「讲解已生成，句子尚未收录」，支持只重试收录，不重复请求 AI。见 F9。

> 说明：`annotation` 是 `/api/explain` 返回并随本次讲解暂存的可选语音教学数据。讲解页聚焦理解句意，不展示该字段；首次从讲解进入跟读时可将已有数据传给跟读页使用。真实音高曲线不属于当前 Stage 4 范围，见后续版本路线图。

## 2.4 F3 口语评估（规格）

**输入**：`audio`（用户录音 webm/opus 或 mp4/aac，客户端探测后上传实际格式，后端统一转码为评估格式）、`sentence`（参考文本）、`lang`。

**输出**：

```json
{
  "overall": 87,
  "accuracy": 90,
  "fluency": 85,
  "completeness": 95,
  "speakingRate": { "wpm": 140, "referenceWpm": 160, "verdict": "偏慢" },
  "words": [
    { "word": "biblioteca", "accuracy": 72,
      "errorType": "Mispronunciation",
      "feedback": "该词发音不够准确，可多听示范" }
  ],
  "suggestions": ["第 2 个词准确度偏低，多练几遍", "语速可稍快"]
}
```

**规则与边界**：
- **语速**：由 Azure 返回的词级时间戳算出「词/分钟」，与西语母语基准（约 150–180 词/分）对比，给出「偏慢/适中/偏快」，作为参考指标（不是硬性扣分项）。
- **连读说明**：连读**不做独立分数**（无 API 能直接评连读），它通过 `fluency` 间接体现；连读的「该在哪连、怎么连」由 F2 的 `annotation.liaison` 讲解。
- 录音 < 1 秒 → 提示「没录到声音，请重试」。
- 单次录音最长 30 秒：录到 25 秒提醒，接近上限时自动停止；该段录音先保留在当前页面，用户确认已读完整后才能评分，也可选择重新录制。评分失败、限额或服务忙时不自动重试，当前页面保留录音并提供手动重试/重新录制；刷新或离开页面不持久化该音频。
- 无麦克风权限 → 提示开启权限（HTTPS 下才可用）。
- 整句读错/读成别的 → 完整度分大幅下降，提示「与原文不符」。
- **能力边界**：韵律分（prosody）与音节级准确度 Azure 仅支持 en-US，西语（es-ES/es-MX）不返回；重音/语调不做客观评分，由 F2 讲解 + F4 示范辅助。
- **词级反馈的下一步**：用户选中有可靠对应的原句单词后，可在该词反馈区按需播放标准发音；记录复练时，若最近一次评分有可靠对齐的目标词，也可在复练目标旁按需播放该词。只在用户点击时请求现有词音 TTS，不预生成；保留整句示范。词音频不等同于连贯语流，也不增加单词专项录音评分。插入词、未可靠对齐的词不伪装成可定位的原句薄弱词。
- **再读一次**：下一轮录音时保留上一轮的简短练习目标，直到新评分替换它；不得把上一轮分数误显示为新一轮结果。
- **提升方向**：即时评分、记录详情和复练目标使用同一套规则，优先采用可靠对齐的薄弱词；没有可靠词级问题时，使用准确度、流利度、完整度及可用语速形成句级目标。反馈缺失或格式异常时说明无法定位具体词，并安全降级；不得虚构发音问题。即时总分为 100 时隐藏「下次留意」目标；分项分数和逐词反馈仍保留，供用户查看评分依据。
- **满分反馈**：新评分结果首次成功得到 100 分时，在总分附近播放一次短暂的星光与微粒效果，以暖金和香槟金为主、少量蓝色呼应品牌；不添加额外鼓励文案，不遮挡评分明细。恢复快照或查看历史不重播，尊重系统减少动态效果设置。

## 2.5 F4 示范朗读（规格）

- **输入**：整句或选中的原句单词、`lang`、可选语速（0.6–1.2x）。
- **输出**：① 西语标准示范音频（Azure 神经语音，音色由当前方言设置 `lang` 决定：`es-ES` → `ElviraNeural`，`es-MX` → 对应音色）；② 首次从讲解进入跟读时可展示 F2 已有的 `annotation` 文字标注。复练不为恢复完整标注自动请求 AI。
- **边界**：长句正常处理；含缩写/数字按西语读音。
- **单词播放**：入口只放在选中词的反馈中，按需请求，不预生成全句各词；显示加载、播放/停止与失败重试。单词与整句示范互斥，开始录音时停止音频；避免同一页面内无必要的重复请求。具体短期缓存策略与失效时机留待技术设计。
- **后续版本候选**：在文字标注之上叠加真实音高曲线，当前不实施（见[文档 8](08-ROADMAP.md)）。
- **多音色选择**：v1 只按方言切音色，不做用户自选音色；多音色选择（`/api/tts` 增加 `voice` 参数 + 音色枚举）列入 V2（见[文档 8](08-ROADMAP.md)）。

## 2.6 F7 文字识别（OCR）（规格）

- **输入**：拍照或相册图片（含清晰西语文本）。
- **处理**：浏览器端 Tesseract.js（西语语言包 `spa`）识别 → 填入输入框（**可编辑**，识别错可手动改）。
- **边界**：识别为空/失败 → 提示「没识别到文字，可手动输入」；手写体不保证。

## 2.7 F8 听熟与个人句子库（规格）

- **页面任务**：听熟页用于配置并执行连续听力任务；个人句子库用于浏览/管理或选择要听的内容。两种入口复用同一份本人句子、搜索和日期分组能力，但通过明确的管理模式与选择模式避免操作混淆。听熟首屏不平铺全部句子。
- **句子库组织**：按个人句子首次成功收录时间，以月份 → 日期 → 句子两级日期分组，最新分组优先。每组显示句数并可折叠。支持搜索西语原文和中文译文；不增加练习日期、评分、难度或场景过滤，也不虚构分类元数据。大列表需稳定分页/加载并保持确定的排序，不能因分页边界漏项或重复。
- **管理模式**：听熟页「朗读范围」旁提供「我的句子」入口，进入独立的句子库管理模式。每句可重新学习（只回填选句输入，不自动调用 AI）或移出；移出前确认，移出后不再属于个人集合/听熟候选，练习历史仍保留。管理模式不显示选择控件。
- **选择模式**：听熟页选择「自定义」后进入独立句子库选择模式。未搜索时可逐句勾选，亦可选择整日或整月；组勾选显示全选、未选及部分选中状态。搜索时只对匹配结果提供逐句选择，不能以组操作隐式扩大搜索结果以外的选择。清除搜索、折叠/展开和返回不得清除或扩大草稿选择。
- **草稿与持久化**：进入选择模式时以最近一次已确认选择作为草稿基线。只有按「确认所选」才将有效个人句子 ID 写入当前用户偏好并启用自定义范围；返回/取消不保存草稿。再次进入恢复上次确认的有效选择。移出句子或数据加载后发现失效 ID 时只过滤无效 ID；全失效仍保持自定义空态，不切换到全部。
- **旧设置降级**：废弃的「已学」范围与内置句/练习记录引用不得造成错误播放或页面崩溃；无效选择不计数、不播放，并给出可恢复提示。旧选择不自动导入预置句或旧评分句。
- **连续播放**：显示有效句数，并将句数放在「朗读范围」旁；用户点击「开始播放」后才按顺序请求西语 TTS 并循环。保留暂停/继续、可调语速、1/2/4 秒句间间隔；默认语速 1.0×、间隔 2 秒。进入句子库、调整范围或仅展开「查看句单」不请求 TTS。离开听熟页停止播放并释放音频。
- **本次句子与单句精听**：确定「全部」或「自定义」范围后，听熟页在「朗读范围」旁显示本次有效句数，「我的句子」入口保留在范围附近以支持管理和进入自定义选择；「查看句单」独立放在播放/显示设置之后的「本次句子」区块中，默认折叠。清单只展示本次范围中的句子、可用译文和当前播放标记，不放逐句精听操作。仅打开清单不请求 TTS。整组开始后，在当前播放句下方提供「单句精听」和与整组当前状态对应的播放/暂停操作。进入精听时暂停整组并记住原组上下文；精听句可暂停/继续、上一句/下一句切换。精听期间隐藏句单，突出当前精听句和精听控制；切换范围外句子不允许。当前句音频成功取得后复用同一音频循环，不重复请求 TTS；用户明确改变语速时允许为当前句重新生成一次。结束精听后释放精听音频并恢复原整组的暂停状态，显示「单句精听」与「播放整组」操作，用户主动继续；整组原本空闲时结束后回空闲。失败时可重试，切换/结束/离页时中止请求并清理音频资源，任何时刻最多一个音频源播放。
- **显示与语音分离**：「显示原文」「显示翻译」只控制屏幕文字，默认仅显示原文；不播放中文翻译语音。
- **持久化与边界**：播放范围、参数、显示开关和已确认自定义选择按用户保存；草稿与音频不持久化。设置保存失败不声称已保存；无网络或 TTS 失败时提示并可恢复。扩大分享前仍需完成限流、用量告警与成本控制。

## 2.8 F5 练习历史

- 每次口语评分后，练习记录存云端（Supabase），含 `{ overall, accuracy, fluency, completeness, speakingRate, time }`。
- 评分结果先展示、后保存：保存失败不丢分数，保留结果并支持重试（不重评）。
- 记录页专注评分回顾和复练；个人句子集合负责句子找回与听熟，二者独立。记录详情显示最近最多 5 次总分变化，固定 0–100 纵轴；1 次为单点，2 次为两点比较，3 次及以上连线，不提供四指标切换。最近一次反馈与简短复练目标优先，历史明细默认收起而非删除。
- **复练目标**：由最近一次可靠的已存评分与逐词反馈生成，不保存原始「提升方向」文字，也不跨历史聚合薄弱词。缺失词级反馈、漏读严重或对齐不可靠时，用句子层面的目标降级，不指认不可靠的薄弱词；具体可靠性判定留待技术设计。
- **再练一次**：直接进入轻量跟读，显示上次薄弱词与简短目标，支持按需词和整句示范。可靠对齐的目标词仅随当前标签页的任务快照短期保存；旧快照或无可靠目标词时仍显示句级目标，不提供目标词播放。完整重音、语调与语法讲解通过「查看讲解」按需获取；不为复练自动请求 AI，也不新增原讲解标注的云端持久化。
- 「最近练习」由云端评分记录派生；用户个人句子通过听熟页入口进入独立管理列表找回，两种内容来源和用途不同。
- 数据按用户隔离（见[文档 5](05-DATABASE.md)）。

## 2.9 F9 个人句子集合

- 成功获得 AI 讲解后自动按当前用户收录原句与可用译文，跨设备找回；输入、粘贴和 OCR 只是取得句子的方式，未成功讲解不自动收录。个人句子与评分记录是独立数据，评分历史不因移出个人句子而删除。
- 去重采用共享的 v1 句子身份规则：先去除首尾空白、Unicode NFC 规范化、折叠连续空白并按西班牙语规则转小写，再按句型生成 `s:`（陈述/普通句）、`q:`（疑问句）、`e:`（感叹句）或 `x:`（边界标点混杂或不明确）身份键。普通句唯一的句末句号可省略；疑问句可省略句首 `¿`、句末 `?` 中任一或两者；感叹句对 `¡`、`!` 同理；ASCII `...` 与 Unicode `…` 等价。疑问、感叹、陈述身份彼此不同。保留重音、词语、句内逗号/分号/冒号/引号/括号等标点、句内句号及省略号与普通句号的差别；混合、重复或无法明确归类的边界标点不归并。重复成功讲解不创建重复个人句子。同一用户的评分分组、历史找回及移出后重新收录时遵循同一身份语义；身份键仅用于去重和历史分组，不覆盖或改写原始输入、已有讲解、评分、逐词反馈或各次独立练习记录。历史关联不依赖个人句子条目持续存在。
- 用户可在听熟页进入的个人句子管理列表中重新学习或移出句子；重新学习回填选句输入框，不自动请求 AI。移出前确认；该句退出个人找回与听熟候选，并从有效自定义选择中排除。再次成功讲解可重新收录。清除练习记录保留个人句子；移出个人句子保留历史评分。评分历史不能依赖个人句子仍存在才可读取。
- 不为现有少量测试账号开发旧练习记录自动迁移。清理指定测试数据必须另获明确授权；清理前残留旧偏好按 F8 安全降级，不自动导入系统预置句。

## 2.10 F10 跟读任务与评分恢复

- 移动 Web/PWA 刷新后尽可能恢复原句、译文、已有的必要发音提示及复练薄弱词/目标。只有恢复数据确实不存在、过期或无权访问时才回到选句空态；暂时无法联网时保留可用的短期快照并提供重试。
- 采用当前标签页的最小化短期任务快照与当前用户的已保存个人句子/评分记录两层来源。短期快照只服务继续当前任务及待保存评分，不等于云端已保存；不持久化录音，不补造缺失标注，不自动调用 AI 讲解。
- 录音中刷新：停止录音并提示重录。评估请求中刷新：结果无法确认，不自动重发，提示重新录音。评分已返回但未确认保存：尽可能保留结果、固定记录 ID 与待保存状态；保存中/失败后先核对当前用户云端同 ID 记录及其评分内容，内容一致才可确认已保存；确未保存时才用同一 ID 重试，防止重复记录。同 ID 内容冲突时不得误判已保存或静默覆盖，保留可用快照并提示冲突。数据库主键上的只插入写入是并发裁决点，重试先核对完整持久化评分内容；冲突时不覆盖已有记录。
- 原有保存失败重试、评分结果保留及页面/浏览器返回保护继续有效。本地可恢复副本不能被当作保存成功；无录音持久化意味着不承诺绝对零丢失。v1 使用按当前用户隔离的 `sessionStorage` 快照，任务起始后 24 小时失效；仅覆盖同一标签页刷新/重载，不承诺关闭标签页、跨标签页或跨设备恢复。存储被浏览器禁用时继续在线保存，但提示刷新恢复不可用。

## 2.11 设置页账户信息（S4-6 已确认）

- 设置页显示当前登录账号的昵称与完整邮箱，帮助多个账号的使用者辨认身份。昵称沿用注册时已保存的资料，缺失时给出中性占位；邮箱只在本人设置页展示。默认头像使用克制的西班牙瓷砖纹样，不使用昵称首字，不提供头像上传。
- 本页不展示累计练习次数、平均分或累计学习时长；缺少可靠口径的指标不作估算。
- 提供「退出登录」。若当前标签页仍有未确认保存的评分，退出前明确提示其本地恢复副本将被清除；用户取消时保持登录和评分。退出成功后清理当前账号的短期学习状态，失败时保持当前页并提供重试机会。
- v1 继续只按地区使用现有默认 Azure 音色，具体音色选择留到 V2。用户希望在产品内提交留言并由系统送达，而不是自行写邮件；本轮暂不实现反馈，后续单独确认无付费方案及其额度、数据去向和验收方式，不展示不可用的反馈入口。
