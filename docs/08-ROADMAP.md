# 文档 8 · 版本规划备忘（V2 / V3 及以后）

> 记录所有「后续再做」的功能，防止遗忘；每期开发前对照本清单重新排优先级。

## V2 · 反馈体验打磨（阶段 2）

- **真实语调曲线可视化**：用 Azure TTS 的逐词/音节时间戳 + 音高提取算法，画出母语发音的真实音高曲线，并叠加用户录音曲线对比（产品特色）。
- **跟读页波形对比**：原生示范波形 vs 用户录音波形 的视觉对比。
- **磨耳朵全局播放条**：任意页面控制播放/暂停的全局迷你播放器。
- **逐词可视化着色强化**：评分结果更精细的高亮与详情（音节级需等西语能力支持）。
- **练习历史趋势**：基于云端记录的进步曲线与统计。
- **语法讲解中英对比加强**。
- **多音色选择（默认语音）**：/api/tts 增加 voice 参数 + 每方言音色枚举；设置页恢复「默认语音」选择。v1 已移除该设置，音色暂由方言决定。

## V3 · 真实例句 + 完整听力（阶段 3）

- **真实例句检索**：接入 YouGlish / YouTube 字幕 / OpenSubtitles，为每句找真实语境片段（解决 P3）。
- **完整听力模式**：真实语料磨耳朵——盲听 → 复述 → 看答案（解决 P4 完整版）。

## 暂不规划 / 待定

- 多语言（非西语）、单词卡、排行榜、社交功能。
